JavaScript: Interactividad y dinamismo

JavaScript se trata de un lenguaje de programación con el que puedes agregar interactividad y dinamismo a tu página web. Trabaja sobre el código que ya has escrito con HTML y CSS, por lo que se complementan en el desarrollo de tu proyecto.
Siempre que observes un movimiento al interactuar con cierto elemento, un cuadro de alerta sonando, o un mecanismo de autocompletar en algún cammpo, ten en mente que JavaScript está detrás de todo eso, funcionando.
Algo importante a tener en cuenta es que este lenguaje se puede utilizar tanto en el lado del cliente como en el lado del servidor, utilizando tecnologías necesarias para ello, como Node.js.

Ventajas

Ya tenemos la noción de las ventajas que brinda este lenguaje, recordemos que agrega movimiento a las páginas web, además de permitir el procesamiento y transformación de los datos enviados y recibidos.
Junto con la creación de contenidos que se actualizan de forma dinámica y animada, dando vida a las aplicaciones que antes solo estaban estructuradas estáticamente con HTML y CSS.

Quiero mostrarte algunos conceptos básicos e importantes para que te lleves un poquito más de conocimiento técnico. Con esto, te dará una idea de las enormes ventajas que tiene el uso de JavaScript en el desarrollo web.

Variables

Las variables son contenedores en los que puedes almacenar valores. Primero se declara la variable con la palabra reservada var o let, seguida del nombre que se le vaya a dar.

let nombreDeLaVariable = "Bob";

Existen diferentes tipos de datos que puedes almacenar en las variables, como números, cadenas de texto, booleanos, arreglos y objetos.

Operadores

Un operador es un símbolo matemático que puede actuar sobre dos valores o variable y producir un resultado.
En la siguiente tabla, se muestran algunos de los operadores más comunes en JavaScript:

"Hola " + "mundo!";

Condicionales

Los condicionales son estructuras de código que permiten comprobar si una expresión devuelve true o no, y luego ejecuta un código diferente dependiendo del resultado.
El condicional más comúnn es la llamada if... else. Observemos:

let helado = "chocolate";

if (helado === "chocolate") {

alert("¡Sí, amo el helado de chocolate!");

} else {

alert("Awwww, pero mi favorito es el de chocolate...");

}

Si se cumple el if, se ejecuta el primer apartado, y si no se cumple la primera condición, se ejecuta el bloque dentro del else.

Funciones

Las funciones son una manera de encapsular una funcionalidad que quieres reutilizar, de modo que puedes llamar esa función con un solo nombre. Por ejemplo:

let nombreDeLaVariable = document.querySelector("h1");

alert("¡Hola!");

Estas funciones: document.querySelector y alert, están integradas en el navegador para poder usarlas en cualquier momento.
Si ves algo que parece un nombre de variable seguido de un paréntesis al final, lo más probable es que sea una función. Recuerda que las funciones toman con frecuencia argumentos, pedazos de datos que necesitan para hacer su trabajo; estos se colocan dentro de los paréntesis.
