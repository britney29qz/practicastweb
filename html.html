HTML: Estructura y contenido


El lenguaje HTML es el encargado de la estructura y el contenido básico de una página web. Hay que tomar en cuenta que es el responsable de definir el esqueleto que va a tener, determinando la disposición de los diferentes elementos y su relación entre sí. Es el más utilizado para la construcción de sitios web, pues consiste de una serie de etiquetas o elementos que definen la semántica de cada parte del contenido, por ejemplo, encabezados, párrafos, enlaces e imágenes, entre otros.

Cuando accedes a una página web, no ves el código HTML a simple vista, a menos que presiones la tecla F2.




Ventajas


Hace mucho tiempo, HTML era más limitado; pero con el tiempo ha evolucionado y se han añadido nuevos elementos y atributos que permiten una mayor flexibilidad. Puede incluir texto, imágenes o videos, incorporar música, formularios, enlaces, botones, tablas y otros elementos interactivos. También están los elementos estructurales, como <div>, <header>, <footer>, <nav>, <section> y <article>. Todo esto representa ventajas significativas, ya que permiten crear diseños más coherentes y significativos.

Aquí tienes una lista de elementos esenciales que no pueden faltar en tu estructura HTML:


  • "<!DOCTYPE html>" es el elemento que define el tipo de documento que es, y la versión de HTML que se utiliza.
  • "<html>" es el elemento raíz que envuelve todo el contenido de la página web y que tiene un principio y un fin. Cuando se crea un documento HTML se abre con esta etiqueta <html> y, cuando se termina, se cierra con esta otra </html>.
  • "<head>" es la etiqueta que contiene metadatos, como el título de la página, los enlaces a hojas de estilo CSS y también scripts de JavaScript.
  • "<body>" abarca todo el cuerpo del texto, es decir, aquí se coloca el contenido visible de la página: texto, imágenes y enlaces.
